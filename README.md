# Отчет по проекту: Лендинг кофейни «Kvarta»

## 🛠 Что делал сам, а что с помощью ИИ

- **Дизайн и структура (Claude Artifacts + ИИ):** Первоначальный дизайн и компоновку интерфейса я генерировал с помощью Claude Artifacts, после чего направлял его точечными правками по сетке, шрифтам, мобильной адаптивности и брендовой цветовой гамме.
- **Выбор стека и архитектура:** Я сам определил стек (Next.js 15, Tailwind v4, TypeScript, SQLite), предложил использовать **React Hook Form** для управления состоянием формы, а также спроектировал логику сохранения лидов на бэкенде.
- **Интеграция и тестирование:** Проводил сквозное ручное тестирование: проверял отправку данных, отсечение дубликатов в базе, поведение мобильной клавиатуры и фокуса в инпуте телефона.

## 🤖 Где ИИ ошибался и как я это заметил

1. **Маска телефона:** ИИ изначально предложил сложную реализацию через ручные регулярки и `if`-условия. При тестировании я заметил, что каретка «застревает» на дефисах, а поле невозможно полностью очистить с помощью `backspace`.
   - _Как исправил:_ Я решил отказаться от этих костылей и перейти на проверенную библиотеку `react-number-format` в связке с `Controller` из React Hook Form, настроив фильтрацию источника событий (`sourceInfo.source === 'event'`).
2. **Дедупликация на сервере (10 минут):** ИИ передавал JS-дату в строковом формате ISO с буквой `T` в SQL-запрос `better-sqlite3`. Из-за этого строковое сравнение с форматом SQLite `CURRENT_TIMESTAMP` ломалось, и дубликаты не отсекались.
   - _Как заметил:_ Заглянул в базу данных `leads.db` и увидел дублирующиеся записи с одинаковым номером.
   - _Как исправил:_ Перенес расчет 10-минутного интервала прямо в запрос базы данных через функцию `datetime('now', '-10 minutes')`.
3. **Ложная валидация после сброса формы:** После успешного отправки метод `reset()` сбрасывал значение телефона, но маска мгновенно генерировала событие `onChange`, вызывая ошибку валидации пустой строки.
   - _Как исправил:_ Настроил игнорирование программных изменений в `onValueChange` от компонента маски.

## ⏱ Что не успел / сделал бы иначе

- Не успел внедрить стороннюю библиотеку для всплывающих `toast`-уведомлений (ограничился адаптивным стилизованным баннером-статусом под формой).
- Для продакшн-системы с высокой нагрузкой вместо файловой SQLite на сервере я бы взял полноценную реляционную БД (например, PostgreSQL) с пулом соединений.
